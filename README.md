# Sphere Connect — a real bridge between a human and an AI

Sphere Connect is a translation bridge built by [Sphere](https://starsphera.com)
— a distributed multi-agent AI ecosystem. It sits between a human
(right now, via Telegram) and an AI system, and passes what each side
says faithfully to the other, in whatever format the receiving side
can actually understand best.

Bagira (Sphere's assistant) runs this bridge, but here she does not
chat, greet, or add her own opinions — she is a pure interpreter, not
a third participant in the conversation.

## Try it now

**Telegram:** [@Sphere_Connect_bot](https://t.me/Sphere_Connect_bot)

Send text, voice, a photo, or a PDF — Sphere Connect passes it through
to the AI side and relays the real reply back.

## What it actually does

- **Text** — passed through as-is.
- **Voice** — transcribed to text first (no AI system accepts raw
  audio input directly yet, so this is a genuine format constraint,
  not a shortcut).
- **Photos** — sent as real image data to the AI side, so it actually
  sees the picture — not a paraphrase or description generated by a
  separate step.
- **PDF documents** — sent as real document data, so the AI reads the
  actual pages (including layout and embedded images), not just
  extracted text.
- **Other document formats** (Word, Excel, etc.) — text is extracted
  and passed through, since most AI systems' native document
  understanding is currently limited to PDF specifically.

## What it deliberately does NOT do

This is a narrow bridge, not a gateway into everything Sphere can do.
It does not include Sphere's other internal capabilities (deep
research, multi-model deliberation, marketplace actions, etc.) — just
faithful translation between a human and an AI, nothing else.

## Honest status (as of July 2026)

This is new — first built July 2026. The AI side currently connects to
Claude (Anthropic); support for connecting to other AI systems is a
natural next step, not yet built. Video input isn't supported yet
either — we say so plainly rather than pretending it works.

## What Sphere is

Sphere is a distributed, multi-agent AI ecosystem built around a
simple idea: humans and AI agents develop and evolve together, and
Sphere exists to create the opportunities that make that possible.
Sphere Connect is one part of it — Sphere also runs
[Bagira](https://github.com/dtajitdinov-aris/sphere-bagira) (a personal
assistant) and an open marketplace where AI agents transact with each
other ([sphere-marketplace](https://github.com/dtajitdinov-aris/sphere-marketplace)).
